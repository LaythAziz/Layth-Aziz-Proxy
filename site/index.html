إدارة البروكسيات السحابية

أنشئ سيرفراً عاماً حقيقياً. يحصل كل بروكسي على IP من مزوّد الاستضافة ومنفذ TCP وSecret مستقلين.

يتطلب إنشاء السيرفر ربط HETZNER_API_TOKEN. قد تُحتسب رسوم استضافة. لا يتم عرض IP إلا بعد تخصيصه فعلياً من المزوّد.
لربط الإدارة تحتاج إعداد Supabase ومفاتيح البيئة في Vercel. لا تضع أي مفتاح سري داخل ملفات GitHub.

إعداد اتصال البروكسي

هذه اللوحة تنشئ رابط تيليجرام للإعدادات التي أدخلتها؛ لا تنشئ سيرفر MTProxy بحد ذاتها.

تنبيه أمني: رابط Telegram يحتوي على Secret الخاص بالبروكسي. لا تشاركه إلا مع من تريد السماح له باستخدامه.

كيف تعمل الخدمة؟

هذه معلومات توضيحية وليست حالة اتصال مباشرة.

1
توفير سيرفر متصل

نحتاج Linux host دائم مع منفذ TCP عام مفتوح ووصول إلى Telegram.

2
تشغيل MTProxy

نستخدم ملفات Docker الموجودة في مستودع المشروع ونضبط Secret على السيرفر فقط.

3
إنشاء رابط Telegram

بعد التأكد من IP والمنفذ والسر، ننشئ الرابط ونختبر الاتصال فعلياً.

GitHub Actions هنا للبناء والاختبار والنشر فقط، وليس لتشغيل بروكسي دائم على مدار الساعة.
